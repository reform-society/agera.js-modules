# agera.js-modules

Add-on files for Agera.js, served via jsDelivr.

- **Status:** maintenance only.
- **Owner:** Jens Harvard

## Contents

- `zip/`: postal-code lookup tables (SE, NO, DK, FI).
- `dash/`: legacy counter dashboard script.

## Usage

```
https://cdn.jsdelivr.net/gh/reform-society/agera.js-modules@main/zip/SE.js
```
